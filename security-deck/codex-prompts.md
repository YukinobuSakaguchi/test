# Codex用 イラスト生成プロンプト集

作成日: 2026-10-28 ／ 更新日: 2026-10-29

このスライドのイラストは、いま同梱している `illust/*.svg`（自作ベクター）で完結している。
より描き込んだ絵に差し替えたいときに、手元のCodex（画像生成）で作るためのプロンプトを用意した。
**この資料の作成環境にはcodexがなく、ここに書いたプロンプトは実行していない（生成結果は未確認）。**

## 差し替え手順

1. 下のプロンプトで画像を生成し、**PNG（背景透過、1024×1024）** で保存する
2. ファイル名を下表の `ファイル名`（拡張子だけ `.png`）にして `illust/` に置く（例: `illust/01-broken-key.png`）
3. `python build.py` を実行する。同名の `.png` があればSVGより優先して埋め込まれる
4. 生成した `2026-10-28_個人のセキュリティ対策.html` をブラウザで開いて確認する

PNGが気に入らなければ、そのファイルを削除して `python build.py` を再実行すればSVGに戻る。

## 共通スタイル指示（すべてのプロンプトの先頭に付ける）

```
フラットなベクター調のイラスト。太めの濃紺の輪郭線（#0A2A3C）、角を丸くした形、影やグラデーションなし。
配色は5色だけ: ティール #007A99、淡い水色 #CDE8EF、淡い黄 #FCE9A8、危険を示す赤 #C8452D（使うのは警告部分だけ）、白。
背景は透明。中央に大きなモチーフを1つ、周りに淡い水色の円を敷く。
画像の中に文字・数字・ロゴ・実在サービスの商標は一切入れない。人物の顔は描かない。
正方形 1024×1024。プレゼンスライドの横に置く挿絵として、離れて見ても形が分かる単純さにする。
```

## 注意

- 画像内に文字を入れさせない（日本語の文字は崩れやすく、スライド側のテキストと重なる）
- Google・Apple・各証券会社などのロゴは描かせない（商標・なりすまし防止）
- 配色を変えたいときは、スライドのテーマ（`deck-source.html` 内 `body[data-theme="C"]`）の色に合わせる
