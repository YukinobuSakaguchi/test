# 個人のセキュリティ対策（パスワード・カード漏洩 → パスキー → Google高度な保護機能）

8分（スライド約5分＋実演約3分）の解説スライド。作成日 2026-10-28。

## 使い方

1. `2026-10-28_個人のセキュリティ対策.html` をブラウザで開き、「▶ 再生する」をクリック
2. 操作: `Space` 一時停止/再開 ／ `←` `→` スライド移動 ／ `R` 最初から
3. スライド10（「では、実際に見てみましょう」）で `Space` を押して止め、実演（`demo.md`）へ。再開すると付録1〜3へ進む

## ファイル

| ファイル | 内容 |
|---|---|
| `2026-10-28_個人のセキュリティ対策.html` | 完成版（イラスト埋め込み済みの単一ファイル） |
| `deck-source.html` | 編集用の元ファイル（イラストは `illust/` を参照） |
| `illust/*.svg` | 自作イラスト（正本） |
| `build.py` | 元ファイルから完成版を作る（`python build.py`。同名PNGがあれば優先） |
| `script.md` | 話す原稿、秒数、根拠メモ、確認区分 |
| `demo.md` | 実演の台本と事前チェックリスト |
| `codex-prompts.md` | Codexでイラストを差し替えるためのプロンプト集（未実行） |

## 構成

スライド1〜10（本編・約292秒）＋付録1〜3（疑ったときの初動／実演の流れ／出典と確認状況）。
デザインは slide-deck のテンプレート（エンジン未改変）にテーマC（白×ティール）を適用し、この資料用のレイアウトCSSだけを追加している。

## 注意

- 数値は報道・検索結果ベースで確認したもの。一次ページ未取得の項目と、**Google公式ページの文言照合が未実施**である点は `script.md` 末尾と付録3に記載
