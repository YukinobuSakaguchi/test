# 個人のセキュリティ対策（パスワード・カード漏洩 → パスワード/二段階認証/パスキー → Google高度な保護機能）

初心者向けの解説スライド（手動めくり）。作成日 2026-10-28 ／ 更新日 2026-10-29。

## 使い方

1. `2026-10-28_個人のセキュリティ対策.html` をブラウザで開く（自動では進みません）
2. 次へ: `→` `Space` `Enter` `PageDown`／画面をクリック（右側）／スワイプ。前へ: `←` `PageUp` `Backspace`／画面の左側をクリック
3. `Home` 最初／`End` 最後。URLの末尾に `#10` のように付けると、その枚数から開く
4. 演出の途中で押すと、まず演出が完成状態になり、もう一度押すと次へ進みます
5. スライド18（「では、実際に見てみましょう」）で実演（`demo.md`）に入り、終わったらスライド19へ

## 構成

本編19枚（約6分15秒）＋実演（約3分）＋付録4枚（疑ったときの初動／ことばの辞典／実演の流れ／出典と確認状況）。8分に収める場合はスライド6・12・15・17を飛ばす（`script.md`）。
デザインは slide-deck のテンプレート（エンジン未改変）にテーマC（白×ティール）を適用。手動めくりは、エンジンとは別の小さなスクリプト（`deck-source.html` 末尾の `<script id="manual">`）で実現している。

## 注意

- 数値は報道・検索結果ベースで確認したもの。一次ページ未取得の項目と、**Google公式ページの文言照合が未実施**である点は `script.md` 末尾と付録4に記載
- 書体は游ゴシック指定。Windows/Mac標準では游ゴシック、それ以外の環境では代替書体になり、文字幅が少し変わることがある
