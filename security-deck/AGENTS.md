# このフォルダで作業するAI（Codex / Claude）への指示

まず `HANDOFF.md` を読むこと（状態・確定事項・未確認事項・次の作業）。

## 守ること
- 編集の正本は `deck-source.html`。`2026-10-28_個人のセキュリティ対策.html` は `python build.py` で作る生成物なので、直接編集しない。
- slide-deck のテンプレートの CSS/JS エンジン（`deck-source.html` の最初の `<style>` と最初の `<script>`）は変更しない。配色はテーマ層（`<style id="theme">`、`data-theme="C"`）、追加レイアウトは `<style id="deck">`、手動めくりは末尾の `<script id="manual">` で行う。
- 確認できていない事実を確認済みとして書かない。未確認の項目（`HANDOFF.md`「未確認事項」）は、確認するまでスライドで断定しない。特に「Googleの高度な保護機能でパスワードでのログインが禁止される」とは、公式ページで確認するまで書かない。
- 新しい数値は出典（URLと確認日）を `script.md` の根拠メモに残す。レポート外の助言は、スライド上に「発表者の提案」と明記する。
- 本番のGoogleアカウントで高度な保護機能への登録を完了させない（締め出しの恐れ）。実演はテスト用アカウントか画面のみ。
- 説明文は36px以上、出典は28px以上。収まらなければ文字を小さくせず、文言を削るか枚を分ける。
- 変更後は `python build.py` → `node tools/qa2.js` → `node tools/nav.js` を実行し、結果を報告する。実行していない検証は `NOT VERIFIED` と書く。
