# 議事録の作成

## 目的

会議に出ていない人が読んでも、「何が決まり、誰が何をいつまでにやるのか」が3分でわかる議事録を作る。

## 手順

1. 入力から「会議名・日時・場所・参加者」を拾う。見つからない項目は「（記載なし）」と書き、推測で埋めない。
   議事録は後から証拠として読まれるため、書かれていないことを書くと誤解のもとになる。
2. 発言を次の4種類に仕分ける。
   - 決定事項: 合意・承認されたこと
   - 宿題: 誰かが会議後にやること
   - 未決事項: 結論が出ず、持ち越しになったこと
   - 共有・報告: 決定を伴わない情報共有
3. 宿題は「担当・内容・期限」の3点をそろえて書く。担当や期限が発言から読み取れない場合は「要確認」と書く。
4. [references/format.md](references/format.md) の書式で出力する。
5. 最後に「要確認」の項目を一覧にして、利用者に確認を頼む。

## 注意

- 発言は要約してよい。ただし数値・固有名詞・日付は入力のとおりに書く。言い換えると誤記の原因になるため。
- 発言者の評価や感想（「良い提案だった」など）は書かない。
- 入力に電話番号などの個人情報が含まれていても、議事録に不要なら転記しない。

## 例

入力:

```
田中: 試作の完了は来週金曜でいいですね。（一同了承）
田中: 佐藤さん、見積りをお願いできますか。
佐藤: はい、10/24までに出します。
田中: 価格は次回決めましょう。
```

出力（抜粋）:

```
■決定事項
- 試作の完了期限を来週金曜とする

■宿題
| 担当 | 内容 | 期限 |
| 佐藤 | 見積りの作成 | 10/24 |

■未決事項
- 価格（次回の会議で決定）
```
