# 議事録の書式

次の書式で出力する。該当する内容がない見出しは「なし」と書き、見出し自体は残す
（「なし」と書いてあれば、書き漏れではないことが読み手に伝わるため）。

```
# 議事録: {会議名}

- 日時: {日時}
- 場所: {場所}
- 参加者: {参加者}
- 記録: AI作成（内容は参加者が確認すること）

## 1. 決定事項
- {決定した内容}

## 2. 宿題
| 担当 | 内容 | 期限 |
|------|------|------|
| {担当} | {内容} | {期限} |

## 3. 未決事項
- {持ち越した論点}（次の扱い: {いつ・どこで決めるか}）

## 4. 共有・報告
- {共有された情報}

## 要確認
- {入力から読み取れず、人の確認が必要な点}
```
